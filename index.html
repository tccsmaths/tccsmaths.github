本系統修復說明：解決「開不到內裡遊戲」的問題

以往使用相對路徑 (`iframe.src="P6_xxx.html"`) 時，常因本地檔案權限、瀏覽器沙盒或相對路徑找不到而導致空白。本網頁已將 6 款遊戲完整 HTML 直接「內嵌」於 `GAMES_DATABASE` 程式碼中，並使用 `iframe.srcdoc` 與 `Blob URL` 技術，實現 100% 離線即時開啟！

【部署至 GitHub Pages 步驟】

  1. 建立 GitHub 儲存庫 (Repository)，例如命名為 tccs-p6-math。
  2. 將本檔案命名為 index.html 並上傳至儲存庫根目錄。
  3. 前往 Repository 頁面的 Settings ➔ Pages。
  4. 在 Source 選擇 Deploy from a branch，Branch 選擇 main / root 並儲存。
  5. 等待 1 分鐘即可取得全校共用的網址：https://[用戶名].github.io/tccs-p6-math/。

【如何擴充或修改遊戲內容】

如需新增第 7 款課題遊戲，只需打開本 index.html，在 GAMES_DATABASE 陣列內加入新物件即可，格式如下： 

{
  id: "p6_new_topic",
  term: 2,
  title: "新課題名稱",
  senFriendly: true,
  isAvailable: true,
  htmlCode: `<!DOCTYPE html><html>...遊戲 HTML 原始碼...</html>`
}
